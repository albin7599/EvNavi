Abstract

In an effort to empower Electric Vehicle (EV) users and mitigate range anxiety, this project proposes EvNavi, a cross-platform mobile application that serves as a smart EV navigation and route planning guide. EvNavi is designed to help EV drivers map their journeys efficiently by incorporating critical parameters such as vehicle battery percentage and dynamic range adjustments.

The application utilizes Flutter for its front-end to provide a sleek, minimalist H&M-inspired black-and-white aesthetic, creating an intuitive user experience. It features interactive map exploration, origin and destination setting with autocomplete suggestions, and location picking directly on the map. EvNavi's route planning engine computes optimal paths while dynamically adjusting for the remaining battery capacity, ensuring users can confidently reach their destinations or find necessary charging stops along the way.

This comprehensive approach overcomes simple geographic navigation by offering EV-specific insights, fostering a deeper understanding of journey limits, and ultimately enhancing the user's ability to travel in an eco-friendly and confident manner.

CHAPTER 1
INTRODUCTION

1.1 Overview

EvNavi is an interactive, smart Electric Vehicle routing mobility application designed to eliminate range anxiety among electric vehicle drivers. By tracking battery percentages and calculating range metrics dynamically, the app allows drivers to plan their trips securely.

1.2 Objective

The primary objective of this application is to empower EV users by providing them with a reliable tool for battery-aware navigation. By utilizing location services and integrating real-time map tracking, the application aims to offer a comprehensive solution for recognizing distance limits and locating charging points in day-to-day commutes. The minimalist, high-contrast, black-and-white user interface reduces cognitive load and ensures safe interaction while driving.

1.3 Expected Outcome

The expected outcome of EvNavi is to empower individuals who drive electric vehicles by optimizing their navigation routines. Users of this application can expect to gain accurate routing paths, battery limit projections, and charging station visibility. This enhanced comprehension will aid their daily transport choices and contribute to stress-free, eco-friendly commuting.

CHAPTER 2
SOFTWARE REQUIREMENTS SPECIFICATION

2.1 Introduction

This section outlines the software landscape envisioned to support EV drivers through the EvNavi app. It highlights the expected functional boundaries and required features for an effective, usable navigation product.

2.2 Overall Description

The application serves as a comprehensive dashboard and route planner that integrates seamlessly with mapping services. Users need tools that calculate their geographical distance against their actual, real-time electric battery limits to avoid being stranded.

2.3 System Features and Requirements

2.3.1 Functional Requirements

1. Dynamic Trip Planning
Users can select an origin and destination via autocomplete searches or map pin-drops. The system calculates the geographic route and estimates battery usage.

2. Battery & Range Adjustments
Interactive sliders or inputs allow users to declare their current battery capacities and standard range metrics.

3. Real-Time Tracking & Speedometer
While connected to device GPS, the map centers on the current live location and displays travel speeds natively on the screen.

2.3.2 Non-Functional Requirements

1. Premium Aesthetic Usability
A strictly modern, glassmorphic layout employing black-and-white contrasts ensures readabilty and a highly engaging layout flow, preventing driver distraction.

CHAPTER 3
SOFTWARE ADOPTED

3.1 Introduction

This report outlines the development tools and technologies employed for EvNavi to guarantee performance and cross-platform reliability.

3.2 Flutter and Dart

Flutter serves as the chosen front-end framework because it allows the deployment of highly visual, customized iOS and Android builds from a single Dart codebase. It enables the fluid liquid-glass effects and smooth animations integral to the minimalist UI requirements.

CHAPTER 4
THE PROPOSED SYSTEM

4.1 Existing Systems

Major geographical routing engines such as default Google Maps calculate shortest or fastest paths based on traffic. However, they lack native integration for EV-specific variables like battery discharge rates or charge-point discovery without breaking the main route context.

4.2 Proposed EV Route Engine

EvNavi proposes a layered system architecture where routing data from mapping APIs is post-processed against the selected EV’s range constraints. The UI immediately highlights whether a trip is achievable on current battery levels, proposing charging waypoints if not.

CHAPTER 5
IMPLEMENTATION

5.1 User Interface Development

Implemented strictly adhering to H&M-inspired monochrome visual palettes. Key implementations include dynamic translucent overlay cards, responsive map markers, and minimalist floating control bars that adapt dynamically depending on the active routing state.

5.2 Testing and Validation

Thorough testing across Android and iOS emulators is conducted to assure location permission handling gracefully falls back, and the map layers smoothly pan and tilt based on touch interactions.

CHAPTER 6
CONCLUSION AND FUTURE WORKS

EvNavi introduces a sophisticated mobile solution specifically tackling electric vehicle mobility concerns. It successfully merges robust mapping engines with EV range calculations in a visually commanding format. Future enhancements could include Augmented Reality (AR) windshield overlays to project turns safely and Integration with live Charging Point availability APIs to ensure real-time reservation.
